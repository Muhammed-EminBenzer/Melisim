🚀 Yayına Al

Siteyi Ücretsiz Yayınla

GitHub Pages ile tamamen ücretsiz, kalıcı bir adres al.

1

GitHub Hesabı Aç

github.com adresine git ve ücretsiz hesap oluştur.

2

Yeni Repository Oluştur

"New repository" butonuna bas. İsim: sevgilim (veya istediğin bir isim). Public olarak ayarla.

3

Dosyaları Yükle

"Upload files" seçeneğiyle tüm site dosyalarını yükle: index.html, style.css, script.js, photos/, songs/

4

Pages'i Aktif Et

Repository Ayarlar → Pages → Source: "Deploy from a branch" → Branch: main → Save

5

Adresini Al! 🎉

Birkaç dakika içinde https://kullaniciadın.github.io/sevgilim adresi aktif olacak.
